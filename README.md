# vbm-journal
The verified journal component of the VBM family: the specification as a Lean model with proofs (slice 1), the verified implementation over a minimal write+fsync shim in the style of vbm-rt (slice 2), and the library made consumable by a host that keeps JSON lines (slice 3). Landed directly with vbm-land; Tier 1 is the build, the proofs and the axiom, sorry and new-C checks. Licence: Apache-2.0.
Slice 1 is in `VbmJournal/` (the model) and `VbmJournalProofs/` (the proofs); see `docs/slice1.md`.
Slice 2 is the driver over the shims (`VbmJournal/Driver`, `Real`, `Sim`, `Sig`, `Sha256`), the trusted C (`native/vbm_journal.c`) and the proof that the driver is the model (`VbmJournalProofs/Impl`, `SigWorld`); see `docs/slice2.md` and `docs/trust-ledger.md`.
Slice 3 is the flat-buffer reader and its refinement proof (`VbmJournal/Scan`, `Basic`; `VbmJournalProofs/Flat`), the line, the signature file and the host's record as parameters, and the JSON-lines journal (`VbmJournal/Json`, `VbmJournalProofs/Json`); see `docs/slice3.md`.
