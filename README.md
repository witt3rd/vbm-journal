# vbm-journal
The verified journal component of the VBM family: the specification as a Lean model with proofs (slice 1), the verified implementation over a minimal write+fsync shim in the style of vbm-rt (slice 2), and lung switching to it (slice 3). Landed directly with vbm-land; Tier 1 is the build, the proofs and the axiom, sorry and new-C checks. Licence: Apache-2.0.
